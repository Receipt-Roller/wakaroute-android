## 1. 先に決めないと出せないもの

### targetSdk 36 — **対応済み。ただしチームの作業が1つ残っています**

Google Play は 2026年8月31日から、**新規アプリと更新の両方**に `targetSdk 36`（Android 16）を要求します。ワカルートは新規アプリなので、この日以降に提出するなら必須です。

**ビルド側は上げ終わっています:**

| | 前 | いま |
|---|---|---|
| AGP | 8.6.0 | **8.11.2** |
| Gradle | 8.11.1 | **8.13** |
| compileSdk / targetSdk | 35 | **36** |

AGP は **8.11 系のうち最新**にしてあります。8.11 が `compileSdk 36` に対応する**いちばん低い系列**だからです — 系列が上がるごとに要求する Android Studio も上がるので、8.13 にすると Otter が要ります。

**残っている作業: チームの Android Studio を Meerkat (2024.3.1) 以上に上げること。**

いまの Studio では `incompatible version` でプロジェクトが開けません。**ビルドは動きます** — Gradle は CLI でも CI でも AGP 8.11.2 を普通に使います。開けなくなるのは IDE だけです。

上げたときに壊れたのは1か所だけでした（新しい lint の `UseKtx`、`KeystoreSecretStore` を KTX の `edit(commit = true)` に書き換えて解消。同期書き込みという性質は変えていません）。

### 署名鍵

`app/build.gradle.kts` は `keystore.properties`（gitignore 済み）を読みます。無ければ署名なしでビルドが通るだけなので、CI は今までどおり動きます。

鍵の作成とパスワードの管理は**開発者本人の作業です。** `keystore.properties.example` に手順があります。

- `.jks` とパスワードは、このノートPCが壊れても残る場所にバックアップしてください
- Play は自分の鍵で署名するので、**アップロード鍵**を失っても Google に再設定を頼めます。ただし本人確認が要り、すぐには終わりません

## 2. データ セーフティ フォームの回答

**このアプリは解析もクラッシュ収集も入れていません**（プライバシーポリシー §9、AGENTS.md）。それが下の回答のほとんどを決めています。

### 収集するデータ

| 種類 | 収集 | 共有 | 必須 | 目的 |
|---|---|---|---|---|
| **メールアドレス** | はい | いいえ | **いいえ（任意）** | アカウント管理のみ — 機種変更で学習記録を引き継ぐため。設定しなければ預かりません |
| **アプリ内のアクティビティ（学習の進捗）** | はい | いいえ | はい | アプリの機能そのもの（理解マップ・進捗・学習時間） |
| **ユーザー ID** | はい | いいえ | はい | アプリの機能（端末登録で作る匿名の学習者 ID） |

### 収集しないデータ

位置情報、連絡先、カメラ、写真、ファイル、通話・SMS、カレンダー、健康、金融情報、端末 ID・広告 ID、**クラッシュログ、診断情報、アプリのパフォーマンス**。

マニフェストの権限は `INTERNET` と `ACCESS_NETWORK_STATE` の2つだけです。

### そのほかの設問

- **データは転送時に暗号化されますか** → **はい**（すべて HTTPS）
- **ユーザーはデータの削除を要求できますか** → **はい**（アプリ内: その他 →「学習記録を削除する」）
- **データ収集は必須ですか、任意ですか** → 学習記録は機能に必須。**メールアドレスは任意**
- **広告目的の共有** → なし
- **第三者へのデータ販売** → なし
- **ファミリー向けポリシーの対象か** → 下の「対象年齢」を参照

## 3. 対象年齢とコンテンツ レーティング

- **対象ユーザー**: 中学生（おおむね 12〜15歳）。iOS の年齢制限は **4+**
- **子ども向けとして扱われます。** 13歳未満が含まれるため、Play の **ファミリー向けポリシー**の対象になります。広告なし・アプリ内購入なし・解析なしなので要件は満たしていますが、フォームで「子ども向け」を選ぶと審査が厳しくなります
- コンテンツ: 暴力・性的表現・薬物・ギャンブル・ユーザー生成コンテンツ **すべてなし**
- **アプリ内購入なし。広告なし。** 完全無料

## 5. アップロードする成果物

**Gradle は JDK 21 で動かしてください。** Studio 同梱の JBR 25 では Gradle 8.13 が動きません（AGENTS.md 参照）。

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
./gradlew :app:bundleRelease
```

- **App Bundle**: `app/build/outputs/bundle/release/app-release.aab`
- **マッピングファイル**: `app/build/outputs/mapping/release/mapping.txt`

**マッピングファイルは毎回いっしょにアップロードし、そのビルドの分を保管してください。** R8 が名前を書き換えるので、これが無いと Play の事前起動レポートのスタックトレースが読めません。ビルドし直すと別のファイルになります。

### 画像素材

`docs/store/` に入っています。**そのままアップロードできます。**

- アプリアイコン **512×512** → `docs/store/play-icon-512.png`
- フィーチャーグラフィック **1024×500** → `docs/store/feature-graphic-1024x500.png`
  （マークを地の色に置いただけのものです。デザインを起こすなら差し替えてください）

**まだ要るもの**

- スマートフォンのスクリーンショット **2枚以上**
- 7インチ・10インチ タブレットのスクリーンショット（タブレットでも配信する場合）

**注意: 実機 XQ-DC44 は 1080×2520 で、長辺が短辺の 2.33 倍あります。**
Play は **長辺を短辺の2倍以内**に制限しているので、撮ったままでは通りません。
1080×1920 に切るか余白を足す必要があります。

## 7. 教科をリリースなしで増やす（`GET /api/prerequisites`）

**アプリ側は対応済み。サーバー側が未実装です。**

国語・英語・理科・社会は MANABU2 にコンテンツがありますが、前提関係の辺が書かれていないので
「準備中」のままです。辺を配信すれば、**すでに入っているアプリにそのまま出ます。**

### 必要なエンドポイント

```http
GET https://wakaroute.com/api/prerequisites
→ 200 application/json
```

```json
{
  "asOf": "2026-08-08",
  "graphs": [
    {
      "asOf": "2026-08-08",
      "subject": "国語",
      "domains": [
        { "code": "A", "name": "読む", "pathId": "<MANABU2 の pathId>" }
      ],
      "elements": [
        { "courseId": "<MANABU2 の courseId>", "title": "説明文を読む", "domain": "A", "grade": 1, "requires": [] },
        { "courseId": "<MANABU2 の courseId>", "title": "論説文を読む", "domain": "A", "grade": 2,
          "requires": ["<説明文を読む の courseId>"] }
      ]
    }
  ]
}
```

- **形は同梱ファイルとまったく同じです** — `core/src/main/resources/graphs/prerequisites-math.json` が
  そのまま1件分になります。まず数学をこの形で配信すれば、往復で確認できます。
- **認証は要りません。** 学習者のデータではないので、`/api/schools` と同じ扱いです。
  認証必須にすると、アカウントを作っていない生徒に教科が出なくなります。
- **`graphs` に無い教科は「準備中」です。** 載せれば出て、外せば消えます。
- `subject` は表示名そのまま（`国語` `数学` `英語` `理科` `社会`）で突き合わせます。

### アプリが受け取ったあとにやること

- 同梱グラフと**同じ検証**（重複・行き先のない辺・宣言のない領域・循環）。落ちたら保存しません
- **`requires` が1本も無い教科は出しません。** 辺の無いグラフは全要素が「学習できる」になり、
  地図が「つまずきはありません」と答えてしまうためです
- 検証を通ったものだけ `filesDir` に保存し、次回起動から使います
- 取得に失敗したら、いま持っているものをそのまま使います

### 誰が辺を書くのか

これは**教科の判断**であって、実装ではありません。数学のグラフにも
`"source": "draft — …教科の判断としてレビューが必要"` と書いてあります。
